29 Spring security in depth
    a. Form based authentication -> session, used by default , default login/out page and /louout URL.
    b. Basic authentication -> Base64 encoded username+password as a request header :"Basic base64encoded"
    	NOTE: above 'a'+'b' are together available by default 
    c. CSRF -> csrf token/ csrf token is of no use in REST(stateless), just disable csrf.
               same site cookies : enable in application.properties
    d. CORS           
    e. String user credentials
       .. storing in memory (RAM) -> UserDetailsService + InMemoryUserDetailsManager
       .. storing in database (via JDBC in H2) -> UserDetailsService + JdbcUserDetailsManager
    f. Encoding , Hashing and  Encryption
    g. Storing Bcrypt Encoded passwords - BCryptPasswordEncoder 
    h. JWT -> Creation(Encoding), sending to server(Bearer ) , getting it verified(Decoding)
	DECODING PART is as follows:       
       .. Using oauth2ResourceServer.java class in filterChain
       .. Creating public + private key pair (using KeyPairGenerator) java class
       .. Creating RSA key object using above key pair (using RSAKey class + nimbus)
       .. Create JWKSource using above RSA key object (usuing JWKSource class)
       .. Creating RSA public key for decoding (using JwtDecoder class)

        CREATING JWT KEY/ENCODING part is as follows:
       .. Creating jwt encoder (using JwtEncoder class + JWKSource)
       .. Creating JWT resource for jwt token creation (via Basic auth)
       .. Using jwt encoder for token creation (in JwtAuthenticationResource.java class)
    i. Authenticating a request (AuthenticationManager class)
    j. Security Authorization -> Globl security  + Method security(@Pre/@post and jsr250)
